# AdZero v0.23.5

修复桥接 LAN 切换代理后 DNS 统计不增长的问题。部分代理会在桥成员上提前重定向请求，旧版只观察主网桥的 53 端口，因此无法把请求和应答对应起来。

- 同时观察主局域网网桥及其成员接口，用接口索引限制范围；保留请求／应答关联及重复包去重，不混入 WAN。非桥接接口沿用原路径。
- 对命中当前规则但收到 SERVFAIL 的查询单独提示，不把 DNS 故障、超时或孤立应答当作已拦截，也不加入最近拦截及效果检测成功凭据。
- 保留同次开机的累计数、清零功能和隐私边界；不改代理、DNS 上游、防火墙规则、缓存或用户过滤列表。
- 在线文档补充统计不增长和拒绝应答被代理转换的排查说明。

已完成 38 项原生统计回归、426 条 LuCI 断言，以及真实网桥／veth／独立客户端／nft DNAT 的隔离 UDP/TCP 测试。真机只读对照确认候选采集可完整关联 6 次查询及应答；未在路由器安装候选包或重启服务。

注意：NaiLink / mihomo 路径实测存在「本地 DNS 桥返回 REFUSED、客户端收到 SERVFAIL」的转换。此版修复采集遗漏并解释这种应答，不修复 NaiLink 自身的转换行为，也不把 SERVFAIL 虚算成拦截。详细证据与验证边界见 [桥接 DNS 统计](BRIDGE_DNS_STATISTICS.md)。
