正式版本为 $release。不按 CPU、固件品牌或 Beta 拆分版本；请统一使用安装菜单。

为什么还保留 IPK 和 APK？

它们是两种原生软件包格式，不是两个功能版本。插件仅含 shell、ucode、LuCI 与图片资源，IPK 使用 all、APK 使用 noarch；同一格式的插件本体跨三个固件共享。安装器自动选择格式，原生包管理器负责检查运行库与依赖。

编译过的依赖不能跨 ABI 通用。x86/64、armsr/armv8、rockchip/armv8、mediatek/filogic 等目标使用各自系统的依赖；aarch64_generic 和 aarch64_cortex-a53 也不能仅因同为 ARM64 就混装原生库。

构建验证基础

已有官方 SDK 验证覆盖 OpenWrt 24.10.8、25.12.5、25.12.6，以及 ImmortalWrt 24.10.6、25.12.2 的对应 x86/64 与 ARM64 目标。通用版本不再以固件小版本白名单选择插件本体，而是检查本机实际软件包、依赖求解和冲突。其他旧版本、裁剪固件、第三方魔改源不作无条件兼容承诺。

测试与真实设备的边界

SDK 编译、原生软件包求解和隔离回归测试分别记录。它们不代表所有物理设备的 LAN、IPv6、各代理组合与回滚路径都经过现场验收。本版本不在你的在线路由器上执行升级、重启或切换代理；首次安装也不会自动接管正在工作的 DNS。

历史测试包与下载链接保留供恢复追溯；日常安装和更新请使用同一个正式入口，无须选择历史版本。
