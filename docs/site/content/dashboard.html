四个页面怎么用

顶部依次为「运行概览」「过滤规则」「访问控制」「DNS 增强」。页面地址会保留当前菜单，可收藏，也能使用浏览器前进、后退切换。输入 DNS 或域名时，后台刷新会保留焦点；离开页面前会提示尚未应用的更改。

概览中的「代理接入」可展开查看各插件运行状态和当前接入。已识别、可适配和实际过滤通过是不同阶段；最终效果仍需在电脑验证。

卡片、列表、导航和开关提供悬停高亮与轻微位移，按钮提供按下反馈。编辑、删除和添加使用明确的图标与边框；已添加状态保留清晰标识。键盘操作有焦点框，触屏不依赖悬停；系统开启「减少动态效果」后会停用位移动画。

读懂四个数据

数据含义
已拦截 DNS 请求在可观察范围内收到的拦截应答，表示请求次数，不是网页广告个数。
已观察 DNS 请求局域网明文 UDP/TCP DNS 查询。设备缓存、加密 DNS、绕过路由器的请求可能不计入。
规则域名当前加载的有效域名数量，不是本次拦截数。
当前接入当前已适配的代理或路由器 DNS；不表示所有终端已经过效果验证。

请求数和拦截数为本次开机或上次清零以来的累计统计，每秒自动刷新，页面在后台时暂停刷新。概览中的「暂停时长」用于临时关闭保护，不是统计时间范围，不会筛选或清零这些计数。没有新查询、没有新拦截应答或客户端直接用缓存时，数字保持不变是正常现象。

DNS请求拦截占比 = 已拦截 ÷ 已观察请求，不代表网页广告拦截率，剩余比例也不代表漏拦广告。占比受正常请求、设备重试和缓存影响，不以比例越高作为过滤越好的依据。

清零统计

点击统计下方「清零统计」，同时重置请求数、拦截数和当前诊断计数，比例从同一时刻重新计算。规则数量、配置和最近拦截不删除，也不重启 DNS 或代理。路由器重启后重新计数。

DNS 应答耗时

正常解析和拦截应答分别计算平均耗时；同时列出慢应答和 15 秒内未观察到应答的数量。样本包含缓存影响，属于当前客户端路径观察，不能当作上游服务器纯测速或缓存命中率。

临时暂停与恢复

严格 DNS 模式下不提供临时暂停，以免移除保护路径；需要时先关闭严格模式，或使用保护总开关关闭并恢复。

遇到网页或 App 异常时，在「暂停时长」选择 5、15 或 30 分钟，再点击对应的「暂停 5／15／30 分钟」按钮。只选择时间不会暂停保护，也不会改变统计范围。到期由路由器尝试恢复；页面关闭也会继续计时。恢复失败会保留提示，检查原因后再处理。

保护总开关、暂停为即时操作；规则和访问控制的草稿需要点击应用。看到任务正在进行时等待完成，不要手动删操作锁。

为什么还要效果检测

“规则已加载”只说明配置完成；电脑可能使用其他 DNS、IPv6 路径或加密 DNS。效果检测从真实电脑发出页面指定的查询，确认它确实经过当前过滤路径。它与过滤规则中的“手动校验”用途不同。
