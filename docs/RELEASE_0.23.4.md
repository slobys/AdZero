# AdZero v0.23.4

修复统一安装器对 OPKG 已安装状态的误判。此前只接受 `install ok installed`，会把带 `user`、`hold` 等正常标记的已安装包当成缺失，提示“本机原生软件包清单不完整”。

- 以原生查询成功、包名精确匹配且实际状态为 `installed` 判断安装情况；接受正常安装标记，不接受仅解包、残留配置、查询失败、错误包名或重复记录。
- 同时修复安装、升级、依赖补充和卸载归属检查使用的同一判定。基础清单不完整时明确指出 `base-files`、`luci-base` 或 `rpcd` 中未确认的具体包。
- 增加三种固件、正常 OPKG 标记和失败状态回归，以及来自固定 SHA-256 官方镜像的真实 OPKG / BusyBox 检查；读取私有数据库副本，不安装软件包、不修改路由器。
- 继续使用同一正式安装入口和共享 IPK/APK；保留原生依赖、系统包替换、ABI、备份与旧保护恢复检查，不借用其他固件的依赖。

用户截图来自 iStoreOS 24.10.7 x86_64；截图能定位到清单检查阶段，尚不能确认该朋友设备具体哪一个包的状态。此修复已在隔离环境复现相同错误并验证；不代表已经在那台设备完成安装验收，也不保证后续软件源与依赖一定齐全。
