# 固件兼容

OpenWrt、ImmortalWrt、iStoreOS 共用同一个正式版本和[统一安装入口](INSTALLATION.md)。不需要选择品牌专用版、ARM64 版或 Beta。

| 固件 | 推荐基础 | 依赖来源 |
| --- | --- | --- |
| OpenWrt | 带 LuCI 的 24.10 / 25.12 | 本机原有软件源 |
| ImmortalWrt | 带 LuCI 的 24.10 / 25.12 | 本机原有软件源 |
| iStoreOS | 带 LuCI 的 24.10 / 25.12 | 原厂源；已知缺失组件按精确构建补齐 |

插件只含 shell、ucode、LuCI 与图片资源，使用一份 all IPK 和一份 noarch APK。这是两种原生包格式，不是两个功能版本；由安装器自动选择。

编译依赖仍按本机 ABI 匹配，不能把其他品牌或架构的运行库强装进来。新安装默认不开启保护；升级保留旧开关。原生依赖求解、系统包替换、版本回退、ucode ABI、配置恢复和操作锁检查继续保留。

## iStoreOS 原厂依赖补充

| 构建 | 目标 | 格式 |
| --- | --- | --- |
| 24.10.8，修订号 2026073111 | x86/64、armsr/armv8、rockchip/armv8 | 原生 IPK |
| 25.12.6，修订号 2026102312 | x86/64、armsr/armv8、rockchip/armv8 | 原生 APK |

六组依赖合并在同一发行版内部，安装器在需要时自动匹配；其中的旧 AdZero 包不会被复用。已有完整版 tcpdump 不替换。其他 iStoreOS 构建若本机源已满足依赖，也可使用同一插件；否则安全停止，不借用其他修订号的库。

## 验证边界

官方 SDK 基础包括 OpenWrt 24.10.8 / 25.12.5 / 25.12.6 和 ImmortalWrt 24.10.6 / 25.12.2 的对应目标。SDK 构建、原生包求解与隔离回归分别记录，不代表所有物理设备及代理、LAN、IPv6 组合均已现场验收。旧版本、裁剪镜像和第三方魔改源不作无条件兼容承诺。

[在线兼容说明](https://slobys.github.io/AdZero/compatibility.html)。历史 SDK 与测试包记录保留供恢复追溯，不再作为用户选版本的白名单。
